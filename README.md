# クイズアプリ

シンプルでモダンなWebベースのクイズアプリです。
HTML, CSS, JavaScriptのみで構築されており、特別なビルドツールなしで動作します。

## 機能
- 5問のクイズ
- 正解・不正解の即時判定
- スコア表示
- リスタート機能

## 実行方法

### ローカルでの実行
以下のコマンドでサーバーを立ち上げることで、ブラウザからアクセスできます。

```bash
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000` にアクセスしてください。

### プレビュー環境
現在、プレビュー用サーバーがポート3000で稼働中です。
